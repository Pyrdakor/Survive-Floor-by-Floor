# Survive – Floor by Floor

Ein Survival-Spiel von W-Gaming: Erobere ein Hochhaus Etage für Etage zurück.

## Windows-Testversion herunterladen

**[Zum aktuellen Download](https://github.com/Pyrdakor/Survive-Floor-by-Floor/releases/latest)**

1. Bei den Downloads `Survive-Floor-by-Floor-Patcher-Windows.zip` auswählen.
2. ZIP vollständig in einen eigenen Ordner entpacken.
3. `SurvivePatcher.exe` starten. Der Patcher lädt und prüft die Spieldateien.
4. Später denselben Patcher starten, um Updates zu erhalten.

Die einzelnen `survive-…-pack-….zip`-Dateien lädt der Patcher automatisch. Sie sind keine eigenständigen Spielinstallationen.

Frühe Testversion für Familie und Freunde. Internetzugang ist für die Updateprüfung erforderlich. Spielstände liegen getrennt unter `%USERPROFILE%\AppData\LocalLow\Ebene2\Ebene2` und bleiben bei Updates erhalten.

Dieses Repository enthält Downloads und Versionshinweise, keinen Spielquellcode. Lizenzhinweise zu Drittanbieterinhalten werden mit dem Spiel installiert.
